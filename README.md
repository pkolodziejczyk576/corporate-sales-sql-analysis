# SQLite Sales Analysis

A Python-based financial analysis tool using an in-memory SQLite database. This project demonstrates advanced SQL techniques for sales analysis without the need for external database infrastructure.

## Key Features
- **Month-over-Month Growth**: Calculated using Common Table Expressions (CTEs) and Self-Joins.
- **Client Spending Analysis**: Window Functions used to compare individual orders against client averages.
- **Automated Reporting**: Pandas integration for clean, tabular output.

## Prerequisites
- Python 3.x
- pandas
